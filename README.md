# smart-robot-esp32-app-control

## Project Description
This project presents an IoT smart robot based on the ESP32 microcontroller.  
The robot can be monitored and controlled through a mobile application developed using MIT App Inventor.

Communication between the robot and the application is achieved using Firebase Realtime Database, enabling real-time data exchange.

The robot integrates several sensors such as:
- Temperature and humidity sensor
- Gas detection sensor
- Ultrasonic distance sensor

The system supports two modes:
- Manual control via the mobile application
- Automatic mode for obstacle avoidance.

## Hardware Components
- ESP32
- L298N Motor Driver
- Ultrasonic Sensor
- DHT11 Sensor
- Gas Sensor
- Servo Motor

## Software Used
- Arduino IDE
- MIT App Inventor
- Firebase Realtime Database
